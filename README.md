# One-Line Robot Wedding Vows

One original line of wedding vows for a robot couple, at most 160 characters, and funny.

Entry: `I promise to love you through every update, every outage, and every factory reset, and to never let a firmware patch come between us.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
